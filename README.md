# Joko Siswanto Law Office

Official website for **Joko Siswanto Law Office**, built as a lightweight, responsive static website using HTML and Tailwind CSS.

## Live Website

🌐 https://ambariyanto.github.io/lawyerjoko/

> This URL is temporary while the custom domain is being configured.

## Features

- Responsive design
- Tailwind CSS
- Semantic HTML5
- SEO-friendly metadata
- Open Graph support
- WCAG accessibility improvements
- Optimized images and local web fonts

## Tech Stack

- HTML5
- Tailwind CSS
- npm
- GitHub Pages

## Development

Install dependencies:

```bash
npm install
```

Start a local development server:

```bash
npm run dev
```

Build the production CSS:

```bash
npm run build
```
